# Attribution

UC Reconnect is derived from [Jakevin's Universal Control Restarter](https://github.com/Jakevin/universal-control-restarter), using the v1.0.0 source as the starting point. Its MIT copyright and permission notice are preserved in LICENSE.

This release adds input-channel verification, event-triggered reconnect attempts, persistent retries, process-generation checks, bounded helpers, target configuration and an isolated installer. It ships source for its own AppleScript helper. It does not redistribute a patched upstream executable or an Apple system binary.

Apple, macOS and Universal Control are names used to identify the platform and feature. This project is independent of Apple.
